**目标**：完成WebRTC实时语音对话的端到端音频流验证

## 🚀 快速启动（3步）

### 步骤1：生成gRPC Python代码

```bash
cd /Users/dlow/Code/NexusVoice/rtc-bridge

# 安装Python依赖
pip3 install grpcio==1.60.0 grpcio-tools==1.60.0 protobuf==4.25.1

# 生成代码
./generate_grpc.sh

# 验证生成
ls generated/
# 应该看到：asr_service_pb2.py, tts_service_pb2.py, common_pb2.py等
```

### 步骤2：本地测试启动（开发环境）

```bash
# 安装GStreamer（仅需一次）
brew install gstreamer gst-plugins-base gst-plugins-good gst-plugins-bad gst-plugins-ugly
pip3 install PyGObject

# 启动ASR桥接
python3 rtp2grpc_asr.py \
  --listen-host 127.0.0.1 \
  --listen-port 50060 \
  --grpc-host localhost \
  --grpc-port 50051 \
  --session-id test-001 \
  --debug

# 另开终端：启动TTS桥接
python3 grpc2rtp_tts.py \
  --grpc-host localhost \
  --grpc-port 50052 \
  --rtp-host 127.0.0.1 \
  --rtp-port 50061 \
  --session-id test-001 \
  --opus-bitrate 40000 \
  --debug
```

### 步骤3：Docker Compose启动（生产环境）

```bash
cd /Users/dlow/Code/NexusVoice

# 构建镜像
docker-compose -f docker-compose-rtc.yml build

# 启动所有服务
docker-compose -f docker-compose-rtc.yml up -d

# 查看日志
docker-compose -f docker-compose-rtc.yml logs -f rtp2grpc-asr
docker-compose -f docker-compose-rtc.yml logs -f grpc2rtp-tts
```

## 🔧 配置说明

### 环境变量

| 变量 | 默认值 | 说明 |
|------|--------|------|
| `ASR_GRPC_HOST` | localhost | ASR gRPC服务地址 |
| `ASR_GRPC_PORT` | 50051 | ASR gRPC服务端口 |
| `TTS_GRPC_HOST` | localhost | TTS gRPC服务地址 |
| `TTS_GRPC_PORT` | 50052 | TTS gRPC服务端口 |
| `RTC_SESSION_ID` | default | RTC会话ID |
| `DEBUG` | false | 调试模式 |

### 自定义配置

```bash
# 示例：使用远程ASR/TTS服务
export ASR_GRPC_HOST=asr.example.com
export TTS_GRPC_HOST=tts.example.com
export DEBUG=true

docker-compose -f docker-compose-rtc.yml up -d
```

### 测试流程

#### 1. 启动所有服务

```bash
# 启动KMS和桥接进程
docker-compose -f docker-compose-rtc.yml up -d

# 启动后端（在application-local.yml设置 rtc.enabled: true）
cd nexusvoice-backend
source ~/.zshrc
mvn spring-boot:run
```

#### 2. 创建RTC会话

```bash
# 获取JWT Token（先登录）
TOKEN="your_jwt_token_here"

# 创建会话
curl -X POST http://localhost:8081/api/v1/rtc/session \
  -H "Authorization: Bearer $TOKEN" \
  -H "Content-Type: application/json" \
  -d '{
    "roleId": null,
    "modelName": "openai:gpt-4o-mini"
  }'

# 响应示例：
# {
#   "code": 200,
#   "data": {
#     "sessionId": "abc-123-def",
#     "signalingUrl": "ws://localhost:8081/ws/rtc/signal",
#     ...
#   }
# }
```

#### 3. 建立WebRTC连接

使用WebSocket客户端或前端页面：

```javascript
// 连接信令WebSocket
const ws = new WebSocket(`ws://localhost:8081/ws/rtc/signal?token=${token}`);

// 创建PeerConnection
const pc = new RTCPeerConnection({
  iceServers: [{ urls: 'stun:stun.l.google.com:19302' }]
});

// 添加音频轨道
const stream = await navigator.mediaDevices.getUserMedia({ audio: true });
stream.getTracks().forEach(track => pc.addTrack(track, stream));

// 创建并发送Offer
const offer = await pc.createOffer();
await pc.setLocalDescription(offer);

ws.send(JSON.stringify({
  type: 'OFFER',
  sessionId: 'abc-123-def',
  seq: 1,
  ts: Date.now(),
  sdp: offer.sdp
}));

// 接收Answer
ws.onmessage = async (event) => {
  const msg = JSON.parse(event.data);
  if (msg.type === 'ANSWER') {
    await pc.setRemoteDescription(new RTCSessionDescription({
      type: 'answer',
      sdp: msg.sdp
    }));
  }
};
```

#### 4. 验证音频流

## ⚠️ 常见问题

### 问题1：Python依赖安装失败

**症状**：`pip install PyGObject`失败

**解决**：
```bash
# macOS
brew install pygobject3 gtk+3
export PKG_CONFIG_PATH="/opt/homebrew/opt/libffi/lib/pkgconfig"
pip3 install PyGObject

# Ubuntu
sudo apt-get install python3-gi python3-gi-cairo gir1.2-gstreamer-1.0
```

### 问题2：GStreamer插件缺失

**症状**：日志显示"missing plugin"

**解决**：
```bash
# macOS
brew install gst-plugins-ugly  # 包含Opus编解码器

# Ubuntu
sudo apt-get install gstreamer1.0-plugins-ugly gstreamer1.0-libav
```

### 问题3：RTP端口冲突

**症状**：桥接进程启动失败"Address already in use"

**解决**：
```bash
# 检查端口占用
lsof -i :50060
lsof -i :50061

# 杀死占用进程或修改配置
```

### 问题4：gRPC连接失败

**症状**："failed to connect to all addresses"

**解决**：
1. 检查ASR/TTS服务是否启动
2. 检查防火墙规则
3. 使用grpcurl测试连接

## 📊 性能调优

### GStreamer缓冲区配置

在Python代码中调整：
```python
# 减少延迟
appsink.set_property('max-buffers', 5)  # 默认10
appsink.set_property('sync', False)     # 不同步时钟

# Opus编码器
opusenc.set_property('bitrate', 40000)  # 40kbps
opusenc.set_property('frame-size', 20)  # 20ms帧
```

### gRPC流控窗口

```python
channel_options = [
    ('grpc.max_send_message_length', 16 * 1024 * 1024),
    ('grpc.http2.initial_connection_window_size', 32 * 1024 * 1024),
    ('grpc.http2.max_frame_size', 16384),
]
```
