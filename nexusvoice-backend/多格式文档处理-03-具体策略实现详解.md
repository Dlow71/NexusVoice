## 1. PDF处理器

### 1.1 核心流程

```
PDF字节流
   ↓
逐页转换为JPG图片（300 DPI）
   ↓
转换为Base64编码
   ↓
发送给GPT-4V OCR识别
   ↓
文本后处理（清理格式）
   ↓
保存到document_unit表
   ↓
更新进度（实时）
```

### 1.2 关键代码片段

**PDF转图片**:
```java
public static String processPdfPageToBase64(
        byte[] pdfBytes, 
        int pageIndex, 
        String imageFormat) throws IOException {
    
    PDDocument document = Loader.loadPDF(pdfBytes);
    PDFRenderer pdfRenderer = new PDFRenderer(document);
    
    // 渲染为300 DPI的图片
    BufferedImage image = pdfRenderer.renderImageWithDPI(
        pageIndex, 300, ImageType.RGB
    );
    
    // 转换为Base64
    ByteArrayOutputStream baos = new ByteArrayOutputStream();
    ImageIO.write(image, imageFormat, baos);
    byte[] imageBytes = baos.toByteArray();
    
    document.close();
    return Base64.getEncoder().encodeToString(imageBytes);
}
```

**GPT-4V调用**:
```java
// 构建多模态消息
UserMessage userMessage = UserMessage.userMessage(
    ImageContent.from(base64, mimeType),
    TextContent.from(OCR_PROMPT)
);

// 调用模型
ChatResponse response = ocrModel.chat(userMessage);
String recognizedText = response.aiMessage().text();
```

## 2. Word处理器

### 2.1 核心流程

```
Word/Office文件字节流
   ↓
Apache POI解析
   ↓
LangChain4j Document对象
   ↓
DocumentBySentenceSplitter分割（500字符/块）
   ↓
提取每个TextSegment的文本
   ↓
保存到document_unit表
```

### 2.2 关键代码片段

```java
// 使用Apache POI解析器
DocumentParser parser = new ApachePoiDocumentParser();
Document document = parser.parse(inputStream);

// 分割文档（500字符/块，0重叠）
DocumentBySentenceSplitter splitter = 
    new DocumentBySentenceSplitter(500, 0);
List<TextSegment> segments = splitter.split(document);

// 提取文本
segments.forEach((segment, index) -> {
    String text = segment.text();
    ocrData.put(index, text);
});
```

## 5. 消息队列消费者

### 5.1 完整实现

```java
@Component
public class RagDocConsumer {
    
    @Resource
    private DocumentProcessingFactory documentProcessingFactory;
    
    @Resource
    private FileDetailDomainService fileDetailDomainService;
    
    /**
     * 监听RAG文档处理队列
     */
    @RabbitListener(queues = "${rabbitmq.queues.rag-doc-ocr}")
    public void handleRagDocMessage(
            @Payload Map<String, Object> payload,
            @Header(AmqpHeaders.DELIVERY_TAG) long deliveryTag,
            Channel channel) {
        
        RagDocMessage docMessage = null;
        
        try {
            // 解析消息
            MessageEnvelope<RagDocMessage> envelope = 
                OBJECT_MAPPER.convertValue(payload, new TypeReference<>() {});
            
            docMessage = envelope.getData();
            
            // 设置链路追踪ID
            MDC.put(TRACE_ID, envelope.getTraceId());
            
            log.info("开始OCR处理文件: {}", docMessage.getFileId());
            
            // 1. 更新文件状态为处理中
            FileDetailEntity fileEntity = 
                fileDetailDomainService.getFileByIdWithoutUserCheck(
                    docMessage.getFileId()
                );
            
            boolean startSuccess = fileDetailDomainService.startFileOcrProcessing(
                docMessage.getFileId(), 
                fileEntity.getUserId()
            );
            
            if (!startSuccess) {
                throw new BusinessException("无法开始OCR处理，文件状态不允许");
            }
            
            // 2. 获取文件扩展名
            String fileExt = fileDetailDomainService.getFileExtension(
                docMessage.getFileId()
            );
            
            if (fileExt == null) {
                throw new BusinessException("文件扩展名不能为空");
            }
            
            // 3. 选择处理策略
            DocumentProcessingStrategy strategy = 
                documentProcessingFactory.getDocumentStrategyHandler(
                    fileExt.toUpperCase()
                );
            
            if (strategy == null) {
                throw new BusinessException("不支持的文件类型: " + fileExt);
            }
            
            log.info("使用策略: {} 处理文件: {}", 
                strategy.getClass().getSimpleName(), 
                docMessage.getFileId());
            
            // 4. 执行OCR处理
            strategy.handle(docMessage, fileExt.toUpperCase());
            
            // 5. 完成OCR处理
            fileEntity = fileDetailDomainService.getFileByIdWithoutUserCheck(
                docMessage.getFileId()
            );
            
            Integer totalPages = fileEntity.getFilePageSize();
            if (totalPages != null && totalPages > 0) {
                fileDetailDomainService.updateFileOcrProgress(
                    docMessage.getFileId(), 
                    totalPages, 
                    totalPages,
                    fileEntity.getUserId()
                );
            }
            
            boolean completeSuccess = 
                fileDetailDomainService.completeFileOcrProcessing(
                    docMessage.getFileId(), 
                    fileEntity.getUserId()
                );
            
            if (!completeSuccess) {
                log.warn("OCR处理完成但状态转换失败，文件ID: {}", 
                    docMessage.getFileId());
            }
            
            log.info("OCR处理完成，文件ID: {}", docMessage.getFileId());
            
            // 6. 自动启动向量化处理
            autoStartVectorization(docMessage.getFileId(), fileEntity);
            
        } catch (Exception e) {
            log.error("OCR处理失败，文件ID: {}", 
                docMessage != null ? docMessage.getFileId() : "unknown", e);
            
            // 处理失败，更新状态
            try {
                if (docMessage != null) {
                    FileDetailEntity fileEntity = 
                        fileDetailDomainService.getFileByIdWithoutUserCheck(
                            docMessage.getFileId()
                        );
                    fileDetailDomainService.failFileOcrProcessing(
                        docMessage.getFileId(), 
                        fileEntity.getUserId()
                    );
                }
            } catch (Exception ex) {
                log.error("更新文件状态为失败失败，文件ID: {}", 
                    docMessage != null ? docMessage.getFileId() : "unknown", ex);
            }
            
        } finally {
            // 确认消息
            channel.basicAck(deliveryTag, false);
        }
    }
    
    /**
     * 自动启动向量化处理
     */
    private void autoStartVectorization(String fileId, FileDetailEntity fileEntity) {
        try {
            log.info("自动启动向量化处理，文件ID: {}", fileId);
            
            // 发送向量化消息到MQ
            RagVectorMessage vectorMessage = new RagVectorMessage();
            vectorMessage.setFileId(fileId);
            vectorMessage.setUserId(fileEntity.getUserId());
            
            MessageEnvelope<RagVectorMessage> envelope = new MessageEnvelope<>();
            envelope.setTraceId(MDC.get(TRACE_ID));
            envelope.setData(vectorMessage);
            envelope.setTimestamp(System.currentTimeMillis());
            
            rabbitTemplate.convertAndSend(
                "rag.topic.exchange",
                "rag.doc.vector",
                envelope
            );
            
            log.info("向量化消息已发送，文件ID: {}", fileId);
            
        } catch (Exception e) {
            log.error("启动向量化处理失败，文件ID: {}", fileId, e);
        }
    }
}
```

### 5.2 消息流转

```
用户上传文件
   ↓
发送到 rag.doc.ocr 队列
   ↓
RagDocConsumer 消费
   ↓
选择策略处理
   ↓
OCR完成
   ↓
发送到 rag.doc.vector 队列
   ↓
RagVectorConsumer 消费
   ↓
向量化完成
```

## 6. 性能优化技巧

### 6.1 PDF处理优化

```java
// 1. 逐页处理，避免一次性加载所有页面
for (int i = 0; i < totalPages; i++) {
    processSinglePage(i);  // 处理完立即释放内存
}

// 2. 每10页触发GC
if ((pageIndex + 1) % 10 == 0) {
    System.gc();
}

// 3. 限流避免API限制
Thread.sleep(100);  // 每页间隔100ms
```

### 6.2 批量保存优化

```java
// 批量插入而不是逐条插入
List<DocumentUnitEntity> batch = new ArrayList<>();
for (int i = 0; i < ocrData.size(); i++) {
    batch.add(createEntity(i, ocrData.get(i)));
    
    if (batch.size() >= 100) {
        documentUnitRepository.saveBatch(batch);
        batch.clear();
    }
}
// 保存剩余数据
if (!batch.isEmpty()) {
    documentUnitRepository.saveBatch(batch);
}
```

```java
long usedMemoryMB = (Runtime.getRuntime().totalMemory() - 
                     Runtime.getRuntime().freeMemory()) / (1024 * 1024);

log.info("当前内存使用: {} MB", usedMemoryMB);

// 超过阈值时告警
if (usedMemoryMB > 1024) {
    log.warn("内存使用过高: {} MB", usedMemoryMB);
}
```
