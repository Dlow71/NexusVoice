# NexusVoice 前端设计规范（AI 精简版）

## 核心风格
暗黑科技风 + 毛玻璃拟态 + 绿色主题

## 配色（必记）
- **主色**：`#10b981`（翠绿）| **辅助**：`#3b82f6`（蓝）| **危险**：`#ef4444`（红）| **警告**：`#fbbf24`（金）
- **背景**：`linear-gradient(135deg, #0f172a, #1e293b, #0f172a)`
- **文字**：`#e2e8f0`（主）| `#cbd5e1`（次）| `#94a3b8`（辅）| `#64748b`（描述）
- **半透明层**：`rgba(30, 41, 59, 0.6)` + `rgba(15, 23, 42, 0.5)`
- **边框**：`rgba(148, 163, 184, 0.1/0.2/0.3)`

## 间距系统（8px 基数）
```
8px | 12px | 16px | 20px | 24px | 32px
```

- **卡片内边距**：`24px`
- **模态框**：`28px 32px`（上下 左右）
- **并排字段 gap**：`32px`
- **表单项间距**：`24px`

## 关键特征（必须遵循）

### 1. 毛玻璃效果
所有浮动元素必须使用：
```css
background: rgba(30, 41, 59, 0.6);
backdrop-filter: blur(20px);
```

### 2. 发光效果
hover 时添加绿色发光：
```css
box-shadow: 0 0 20px rgba(16, 185, 129, 0.15);
```

### 3. 缓动动画
统一使用：
```css
transition: all 0.3s cubic-bezier(0.4, 0, 0.2, 1);
```

### 4. hover 上浮
```css
transform: translateY(-4px);
```

### 5. 圆角规范
- 最小：`10px`
- 卡片：`16px`
- 模态框：`20px`
- 胶囊徽章：`20px`

### 6. 渐变文字
标题使用绿蓝渐变：
```css
background: linear-gradient(135deg, #10b981, #3b82f6);
-webkit-background-clip: text;
-webkit-text-fill-color: transparent;
background-clip: text;
```

### 7. 顶部高光线
卡片 hover 时显示：
```css
.card::before {
  content: '';
  position: absolute;
  top: 0;
  left: 0;
  right: 0;
  height: 2px;
  background: linear-gradient(90deg, transparent, rgba(16, 185, 129, 0.5), transparent);
  opacity: 0;
  transition: opacity 0.3s;
}
.card:hover::before {
  opacity: 1;
}
```

### 模态框进入动画
```css

    transform: translateY(0);
  }

```

```css
}
```

## 禁止项

❌ **绝对不要使用**：
- 纯白色背景（`#ffffff`）
- 纯黑色背景（`#000000`）
- `linear` 线性缓动
- 小于 `6px` 的圆角
- 无 `backdrop-filter` 的半透明背景
- 突兀的颜色（鲜艳的粉色、黄绿色等）

## 响应式断点

```css
/* 移动端 */
@media (max-width: 768px) {
  .form-row {
    grid-template-columns: 1fr;
  }
  .modal-content {
    max-width: 95%;
  }
}

/* 平板 */
@media (max-width: 1024px) and (min-width: 769px) {
  .modal-content {
    max-width: 90%;
  }
}
```

## 使用指南

### 新建页面时
1. 复制标准组件模板
2. 确保所有浮动元素有毛玻璃效果
3. 所有交互元素添加 hover 动画
4. 使用统一的配色和间距
